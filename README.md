## ⚠️ 郑重免责声明（操作前必看）

1. **变砖风险**：车机属于行车安全系统的一部分，折腾车机有风险（可能导致黑屏、无限重启、系统卡死等）。
2. **保修相关**：因开启 ADB 或安装第三方软件导致的硬件损坏、系统崩溃，4S 店可能会**拒绝保修**或收取系统恢复费用。
3. **安全第一**：请勿在行车过程中、或是车辆未安全停靠的状态下进行任何调试操作。
4. **责任自负**：本仓库所有方法均来自作者个人研究与网络公开资料整理，仅供技术交流。**因按照本教程操作导致的一切后果，作者概不负责。**

## 🛠️ 必备硬件准备（二选一）

本项目支持 **电脑/手机** 双端操作，请根据你的现有设备准备硬件：

* **方案 A：手机操作（最推荐，免抱电脑下车）**
  * 📱 一台安卓手机
  * 🔌 一根 **双公头 USB 数据线** * 🔌 一个 **OTG 转接头**（用于插在手机上，将手机作为控制端）
  * 📲 手机端需要下载 ADB 控制软件（如：*甲壳虫、ADB KIT、Bugjaeger 等，具体见下文*）
* **方案 B：电脑操作（传统方案）**
  * 💻 一台笔记本电脑（Windows / Mac）
  * 🔌 一根 **双公头 USB 数据线**（连接电脑与车机特定 USB 接口）

👉 [点此查看：电脑端/手机端 ADB 环境配置与工具下载指南](./05_通用工具与ADB环境/)
