# 🚗 吉利 2020款（GKUI系统）开启 ADB 教程

> ⚠️ **操作前须知**：本教程仅适用于搭载 GKUI 系统的 2020 款吉利部分车型。折腾车机有风险，请严格按照步骤操作，责任自负。

---

## 🛠️ 准备工作

1. **控制端设备**：准备好笔记本电脑，或者安装了 ADB 工具（如甲壳虫ADB助手）并带有 **OTG 转接头** 的安卓手机。
2. **连接线材**：一根 **双公头 USB 数据线**。
3. **连接接口**：将线一头插在电脑/手机（带OTG）上，另一头插在车机**带数据传输功能的 USB 接口**（通常是靠近驾驶位的那一个，部分车型需要拔掉行车记录仪 U 盘）。

---

## 🚀 核心操作步骤

### 第一步：计算“动态工程暗号”
2020款 GKUI 系统的工程模式暗号是非常特殊的**动态暗号**，需要根据你**当前操作的实际时间**进行计算。

* 📐 **暗号公式**：`#* [当前月份 + 10] [当天日期] [当前小时(12小时制)]`

> 📝 **计算示例（以 2026年7月9日 19点25分 为例）：**
> * **月份**：7月 $\rightarrow$ $7 + 10 = \mathbf{17}$
> * **日期**：9日 $\rightarrow$ $\mathbf{09}$
> * **时间**：19点（下午7点） $\rightarrow$ 12小时制为 $\mathbf{07}$
> * 🌟 **最终输入的暗号即为**：`#*170907`

---

### 第二步：进入车机工程模式
1. 启动车辆，打开车机的 **【拨号盘】**。
2. 根据你当前操作的时间，计算出那一分钟的暗号。
3. 在拨号盘中直接输入计算好的暗号（例如：`#*170907`）。
4. 输入完成后，系统会自动跳转并打开 **【工程模式】** 界面。

---

### 第三步：通过原生指令强制开启 ADB
1. 在进入的工程模式界面中，找到并点击 **【MTK 日志】** 按钮。
2. 进入新页面后，点击屏幕 **【右上角】** 的 **【三条横杠 (菜单)】** 图标。
3. 在弹出的菜单中，找到并点击 **【Run Command】**（运行指令）选项。
4. 在弹出的输入框中，输入以下用于激活安卓底层 ADB 的强制命令（注意空格和下划线）：
   ```bash
   settings put global adb_enabled 1

*(📝 作者注：由于具体车型版本不同，后续开启 USB 调试/ADB 开关的具体名称可能略有差异，请在展开的菜单中寻找含有 “USB 调试”、“ADB” 或 “Log” 相关的开关将其打开。)*

---

## 📲 第四步：连接设备与安装软件

车机端开关打开后：
1. **手机党**：打开手机上的 ADB 软件（如甲壳虫），允许 USB 访问授权，连接成功后即可直接选择手机里的 APK 文件下发安装。
2. **电脑党**：打开命令行输入 `adb devices` 查看是否识别到车机，识别成功后运行 `adb install xxx.apk` 进行安装。
